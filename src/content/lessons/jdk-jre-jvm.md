# JDK vs JRE vs JVM

Understanding Java architecture is critical.

## JVM

Java Virtual Machine executes bytecode.

## JRE

Java Runtime Environment contains:

- JVM
- Libraries
- Runtime files

## JDK

Java Development Kit contains:

- JRE
- Compiler
- Debugging tools

## Flow

```txt
.java → compiler → .class → JVM
```
