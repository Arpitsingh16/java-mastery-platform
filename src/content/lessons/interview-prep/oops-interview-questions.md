# OOP Interview Questions

---

# 1. What is Encapsulation?

Binding data and methods together while hiding implementation details.

---

# 2. What is Inheritance?

One class acquires properties of another class.

---

# 3. What is Polymorphism?

Ability of object to take multiple forms.

Types:

- compile-time
- runtime

---

# 4. What is Abstraction?

Hiding internal implementation and showing essential details.

---

# 5. Difference Between Abstract Class and Interface

| Abstract Class | Interface |
|---|---|
| partial abstraction | full abstraction |
| constructors allowed | no constructors |

---

# 6. What is Constructor Overloading?

Multiple constructors with different parameters.

---

# 7. What is Method Overriding?

Subclass redefines parent method behavior.

---

# 8. What is super Keyword?

Used to access parent class members.

---

# 9. What is this Keyword?

Refers to current object.

---

# 10. What is Association?

Relationship between classes.

Types:

- aggregation
- composition
