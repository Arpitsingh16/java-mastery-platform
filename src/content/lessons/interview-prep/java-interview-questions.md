# Core Java Interview Questions

---

# 1. What is Java?

Java is a:

- object-oriented
- platform-independent
- high-level programming language

---

# 2. Why is Java Platform Independent?

Java uses:

```txt
Bytecode + JVM
```

Bytecode runs on any operating system with JVM installed.

---

# 3. Difference Between JDK, JRE, and JVM

| Component | Purpose |
|---|---|
| JVM | Runs Java bytecode |
| JRE | JVM + libraries |
| JDK | JRE + development tools |

---

# 4. What is OOP?

OOP stands for:

```txt
Object-Oriented Programming
```

Main pillars:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

# 5. Difference Between == and equals()

| == | equals() |
|---|---|
| compares reference | compares content |

---

# 6. What is Method Overloading?

Multiple methods with same name but different parameters.

---

# 7. What is Method Overriding?

Subclass provides specific implementation of parent method.

---

# 8. What is Constructor?

Special method used to initialize objects.

---

# 9. What is the Difference Between Array and ArrayList?

| Array | ArrayList |
|---|---|
| fixed size | dynamic size |
| faster | flexible |

---

# 10. What is Exception Handling?

Mechanism to handle runtime errors safely.
