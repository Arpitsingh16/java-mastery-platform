# JDBC Interview Questions

---

# 1. What is JDBC?

Java Database Connectivity API.

Used to connect Java applications with databases.

---

# 2. What are JDBC Components?

- DriverManager
- Connection
- Statement
- PreparedStatement
- ResultSet

---

# 3. Difference Between Statement and PreparedStatement

| Statement | PreparedStatement |
|---|---|
| vulnerable to SQL injection | secure |
| slower | faster |

---

# 4. What is ResultSet?

Stores data returned from database query.

---

# 5. What is SQL Injection?

Malicious SQL code inserted through inputs.

---

# 6. Why Use PreparedStatement?

- prevents SQL injection
- improves performance

---

# 7. What is Connection Pooling?

Reusing database connections for performance.

---

# 8. Difference Between executeQuery() and executeUpdate()

| executeQuery | executeUpdate |
|---|---|
| SELECT queries | INSERT/UPDATE/DELETE |

---

# 9. What is Commit and Rollback?

Used for transaction management.

---

# 10. What is JDBC Driver?

Software component enabling Java-database communication.

---
