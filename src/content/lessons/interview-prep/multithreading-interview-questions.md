# Multithreading Interview Questions

---

# 1. What is Thread?

Smallest unit of execution inside process.

---

# 2. Difference Between Process and Thread

| Process | Thread |
|---|---|
| heavyweight | lightweight |
| separate memory | shared memory |

---

# 3. How to Create Thread?

Two ways:

- Thread class
- Runnable interface

---

# 4. What is Synchronization?

Controls shared resource access.

---

# 5. What is Deadlock?

Two threads waiting forever for each other.

---

# 6. What is Race Condition?

Multiple threads modifying shared data simultaneously.

---

# 7. Difference Between sleep() and wait()

| sleep() | wait() |
|---|---|
| Thread class | Object class |
| no lock release | releases lock |

---

# 8. What is ExecutorService?

Framework for managing thread pools.

---

# 9. What is Volatile Keyword?

Ensures variable visibility across threads.

---

# 10. What is Thread Lifecycle?

States:

- New
- Runnable
- Running
- Waiting
- Terminated
