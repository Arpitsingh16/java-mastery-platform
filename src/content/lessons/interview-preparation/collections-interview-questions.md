# Collections Interview Questions

---

# 1. What is Java Collections Framework?

Set of classes and interfaces for storing/managing data.

---

# 2. Difference Between ArrayList and LinkedList

| ArrayList | LinkedList |
|---|---|
| fast access | fast insertion |
| dynamic array | node-based |

---

# 3. Difference Between HashMap and Hashtable

| HashMap | Hashtable |
|---|---|
| not synchronized | synchronized |
| faster | slower |

---

# 4. Difference Between HashSet and TreeSet

| HashSet | TreeSet |
|---|---|
| unordered | sorted |
| faster | slower |

---

# 5. What is Iterator?

Used to traverse collections safely.

---

# 6. What is Comparable?

Used for default sorting.

---

# 7. What is Comparator?

Used for custom sorting.

---

# 8. Difference Between List and Set

| List | Set |
|---|---|
| duplicates allowed | duplicates not allowed |

---

# 9. What Causes ConcurrentModificationException?

Modifying collection during iteration.

---

# 10. What is PriorityQueue?

Queue based on priority ordering.
